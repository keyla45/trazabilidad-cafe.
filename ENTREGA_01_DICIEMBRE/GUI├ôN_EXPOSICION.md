# Exposición de resultados — CaféTrace (1 de diciembre de 2026)
**Estructura sugerida de 10 minutos; ajustar al tiempo concedido.**

1. **Problema y objetivo (1 min).** Registro disperso, inventario, seguimiento de pedidos y trazabilidad.
2. **Mapa de las cinco áreas (1 min).** Agricultor, producción, almacén, distribución, tienda.
3. **Demostración principal (3 min).** Ingreso por rol → lote → proceso → inventario → pedido → QR. Usar datos DEMO claramente marcados.
4. **Tecnologías (2 min).** Django/base de datos, MRP, API JSON, analítica, asistente de reglas y dictado por voz cuando exista soporte.
5. **Pruebas con usuarios (2 min).** Mostrar cantidad real de participantes, tareas completadas, incidencias y fotografías/videos autorizados. No inventar métricas.
6. **Resultados, límites y cierre (1 min).** Explicar qué fue validado, qué no y próximas mejoras.

**Antes de exponer:** probar el enlace público, mostrar un QR escaneado desde otro teléfono, tener una copia local para contingencia y ocultar contraseñas/tokens de la grabación.
